# MLB WINTER CITY : SAVE KARINA — 대표보고 대시보드 v4

26FW 다운자켓 매출 극대화 프로젝트 대표보고용 HTML 대시보드입니다.

## 구성
- `index.html` — 대시보드 본문 (6개 탭: 프로젝트 목표 · 임팩트 · WINTER CITY 세계관 · WINTER CITY 플랜 · GLOBAL · 기대효과/예산)
- `assets/` — 이미지(img) · 영상(video) · 폰트(font). 모든 경로는 상대경로(`assets/...`)
- `.nojekyll` — GitHub Pages가 파일을 그대로 서비스하도록 설정

## GitHub Pages 배포
1. 새 저장소를 만들고 이 폴더 안의 파일 전체(`index.html`, `README.md`, `.nojekyll`, `assets/`)를 업로드
2. Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `(root)` → Save
3. 1~2분 후 `https://<계정>.github.io/<저장소명>/` 링크로 접속

## 참고
- 웹 업로드(드래그)는 1회 100개까지입니다. 파일 수가 100개 이하라 한 번에 올릴 수 있습니다.
- 특정 탭으로 바로 열기: 링크 뒤에 `#s1` ~ `#s6` 를 붙이면 해당 탭이 열립니다.
